# 温度カーブ機能の実機検証（2026-10-23 JST）

対象はRadeon AI PRO R9700、BDF 0000:0b:00.0です。
ドライバが公開する5点、hotspot温度25〜100°C、PWM 20〜100%を使用しました。
温度はhwmonのjunction、PWMはpwm1、RPMはAMD SMIとhwmonで測定しました。

## TOML入力と一時設定

```bash
uv run fan_control.py curve --config config/fan-curve.example.toml \
  --gpu 0000:0b:00.0 --settle 10 --seconds 20
```

入力は`25:20 50:45 65:65 85:85 100:100`です。
全5点の書き込み・コミット後の読み戻しが入力と一致し、終了コード0でした。

| 状態 | junction | hwmon PWM | RPM |
| --- | ---: | ---: | ---: |
| 変更前、自動制御 | 36°C | 20.0% | 1,064 |
| カーブ適用、10秒後 | 36°C | 29.8% | 1,578 |

別コマンドの`rocm-smi --showfan --showtemp --json`でも、junction 36°C、
PWM level 76（表示30%）、1,577 RPMを確認しました。
瞬時の表示温度を直線補間して得る数値と実測PWMには差があるため、
設定点の読み戻し一致と、実測PWM/RPMの変化を別々に確認しています。
予定どおり終了時に既定の自動制御へ戻り、手動カーブが全点ゼロに戻りました。

## CLI入力とコマンド終了後の保持

```bash
uv run fan_control.py curve 25:40 50:40 65:60 85:80 100:100 \
  --gpu 0000:0b:00.0 --settle 8
```

上記コマンドが正常終了した後に、別プロセスの`status --json`で測定しました。

* junction 36°C
* PWM 102/255 = 40.0%
* 2,051 RPM
* 5点すべてが指定したカーブと一致

25〜50°Cの区間を40%にしたカーブが、設定プロセス終了後も保持されることを確認しました。
検証用シェルのEXIT処理で`auto`を実行し、標準自動制御へ戻しました。
減速後はjunction 35°C、PWM 20%、1,064 RPMを確認しました。
